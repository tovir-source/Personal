# Victor Alfonso — Personal Portfolio

Editorial portfolio for Victor Alfonso Delgado Bolaños, built with Vite, semantic HTML, CSS, and native JavaScript.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`, then preview it with `npm run preview`.

## Replace personal assets

- Add the real photograph at `public/images/profile.jpg`.
- Add the official SENA logo at `public/images/sena-logo.png`.
- Add the video poster at `public/images/video-poster.jpg`.
- Add the 1–2 minute presentation video at `public/videos/my-introduction.mp4`.

The page includes accessible placeholders until these files are supplied. Additional favorite images can be connected to the `.detail-visual` elements in `src/main.js`.

## Deploy to Vercel

Import the project into Vercel. Use the default Vite settings: build command `npm run build` and output directory `dist`.
